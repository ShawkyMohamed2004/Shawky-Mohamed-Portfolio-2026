## 🎨 Customization

<details>
<summary>🎨 Change Accent Color</summary>

Edit `css/base/variables.css`:

```css
:root {
    --accent-color: #00d4ff;    /* Main accent */
    --accent-secondary: #00ffc8; /* Secondary */
    --accent-rgb: 0, 212, 255;   /* For opacity */
}
```

**Available presets:** `cyan` • `pink` • `purple` • `green` • `orange`

</details>

<details>
<summary>🌗 Theme Settings</summary>

The site supports **Dark** (default) and **Light** modes.  
Users can toggle via the appearance switcher in the navigation.

</details>
