# Shawky Mohamed - Portfolio Website

![Portfolio Preview](images/shawky-gradient-bg.jpg)

## 🚀 About

Professional portfolio website showcasing my work as a **Flutter Developer** and **Software Engineering Student** at FCSE New Mansoura University.

## ✨ Features

- 🎨 **3 Layout Modes**: Modern, Split, and Narrative
- 🌗 **Dark/Light Theme** with custom color picker
- 📱 **Fully Responsive** design
- ✨ **Smooth Animations** and transitions
- 🎯 **Interactive UI** elements
- 📄 **CV Download** functionality
- 🔥 **Creative 3D Effects**

## 🛠️ Technologies

- **HTML5**
- **CSS3** (Advanced animations, Grid, Flexbox)
- **Vanilla JavaScript** (ES6+)
- No frameworks or libraries - Pure hand-coded

## 📂 Project Structure

```
Portfolio/
├── index.html          # Main HTML file
├── css/
│   ├── style.css       # Main styles
│   └── additions.css   # Additional styles
├── js/
│   └── script.js       # All JavaScript functionality
├── images/             # Project images
└── assets/             # CV and other assets
```

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/shawky-mohamed-portfolio.git
```

2. Open `index.html` in your browser

That's it! No build process needed.
